# Lanna Pizza

Site de demonstração da Lanna Pizza — pizzaria artesanal e delivery em Santa Tereza do Oeste - PR. Landing page de convencimento com cardápio interativo, montagem de pizza por sabores e fluxo de pedido. HTML/CSS/JS estático, sem build nem dependências, hospedado na Vercel.

🔗 **Demo ao vivo:** https://lanna-pizza.vercel.app
